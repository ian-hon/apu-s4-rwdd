# EcoQuest

To run, make sure this folder has its level equivalent to htdocs.

Eg:, htdocs/dashboard.php, not htdocs/ecoquest/dashboard.php


### DB Import
Paste the contents of `api/db/create_db.sql` OR `db_export.sql` into the XAMPP SQL section and run it. All tables, fields and mock data will be created.

### DB Delete
Paste the contents of `api/db/delete_db.sql` into the XAMPP SQL section and run it. All tables will be removed.
